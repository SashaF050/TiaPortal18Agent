# Siemens TIA Portal Autonomous Agent & Multi-Tool v2.3.0

Интеллектуальный автономный агент, интерактивный TUI-дашборд и MCP JSON-RPC сервер для прямого управления, глубокого аудита, релокации адресов оборудования, синхронизации сигналов промышленных роботов и оптимизации проектов в **Siemens TIA Portal (PublicAPI Openness V14..V20, нативная поддержка V18 Update 5)**.

---

## 🌟 Ключевые возможности v2.3.0

### 1. 🛡️ Умная защита тегов сетевого оборудования (Smart Device-Aware Protection)
- Автоматический сбор аппаратной конфигурации всех устройств проекта (`GetProjectDeviceAddressRanges`):
  - Частотные преобразователи (ПЧВ / VFD: Inovance, Siemens SINAMICS G120/S120, Danfoss).
  - Промышленные роботы (KUKA, Fanuc, ABB).
  - Станции распределенного ввода-вывода (ET200SP / ET200MP).
  - Пневмоострова (Festo, SMC).
  - Сторонние GSD / GSDML устройства.
- Теги сетевого обмена (%I / %Q, управляющие слова Control Word / Status Word, уставки скорости, сигналы роботов) классифицируются как `Tag-DeviceIO` и надежно **защищены от случайного удаления** в умном очистителе мусора, даже если на них временно нет ссылок в коде ПЛК.
- Резервные каналы контроллера нумеруются по стандарту `Empty_DI_x` / `Empty_DO_x`.

### 2. 🚚 Мастер переезда адресов оборудования и тегов («Мастер переезда» — пункт `[M]`)
- Интерактивная карта распределения адресного пространства (%I и %Q).
- Сдвиг начальных адресов выбранного устройства (например, с `%I100..131` на `%I200..231`).
- **Контроль конфликтов (Pre-flight Conflict Detection)**: автоматическая проверка наложений на адресное пространство других устройств с блокировкой опасных сдвигов.
- Автоматический сдвиг всех привязанных тегов ПЛК в таблицах тегов.
- **Обязательное резервное копирование**: перед каждым переездом автоматически создается снапшот проекта (`DoSaveProjectVersion`).

### 3. 🤖 Синхронизатор сигналов робота KUKA (пункт `[R]`)
- Двусторонняя синхронизация KRL ↔ TIA Portal PLC Tags:
  - Импорт сигналов `$OUT` (входы ПЛК `%I`) и `$IN` (выходы ПЛК `%Q`).
  - **Обратный экспорт (Reverse Export)** тегов TIA Portal в файл KRL с генерацией корректного синтаксиса `SIGNAL Name $OUT[x]` и сохранением комментариев.
  - Полноценная поддержка комментариев (`;` и `//`), кириллицы и секций FOLD.
  - Редактирование в Блокноте (Notepad) прямо из агента.
  - Добавление одиночного сигнала прямо в консоли без перезагрузки всех тегов.
  - Интерактивный выбор тегов по пробелу (`[Space]`) и создание только отмеченных сигналов.
  - Автоматический бэкап перед добавлением тегов.

### 4. 🔍 Диагностика готовности системы и совместимость версий (пункт `[D]`)
- Динамический резолвер сборок `Siemens.Engineering.dll` для любых установленных версий TIA Portal (V14, V15, V15.1, V16, V17, V18, V19, V20).
- Проверка членства пользователя Windows в группе `Siemens TIA Openness`.
- Проверка и автоматическое внесение агента в Белый список Openness (Whitelist Registry) по нажатию `[W]`.
- Мониторинг запущенных процессов TIA Portal и S7-PLCSIM.

### 5. 🖥️ Чистый TUI-интерфейс без артефактов
- Полная очистка экрана и буфера прокрутки (Win32 API + ANSI VT100 `\x1b[3J\x1b[H\x1b[2J`).
- Умный перенос длинных строк (`SafePrintWrapped`) по ширине консоли без наползания текста.

### 6. 🧠 Встроенный AI-ассистент (Skill `tia-portal-engineer`)
- В репозитории в каталоге `.agents/skills/tia-portal-engineer/SKILL.md` сохранен инженерный навык для автономных AI-ассистентов (Google Antigravity, Gemini CLI, Claude Code), содержащий архитектурный контекст и стандарты разработки SCL/LAD.

## 🚀 Запуск и Управление

### Главное меню агента
```cmd
build.bat
TiaPortal18Agent.exe
```

Горячие клавиши главного дашборда:
- `[1]` Сводка проекта и аппаратная конфигурация (CPU, модули, IP-адрес)
- `[2]` Структура вызова (Call Structure, навигация и фильтрация Main OB1)
- `[3]` Структура зависимости (Dependency Graph DB → FC/FB → OB1)
- `[4]` Ресурсы памяти (Memory Resources: Load / Work / Retentive)
- `[5]` Диагностика и компилятор TIA Portal
- `[6]` Умный очиститель мусора (Smart Cleaner с защитой Device-IO)
- `[7]` Пакетный экспорт / импорт (SimaticML XML и SCL)
- `[8]` S7-PLCSIM V18 — Управление симулятором
- `[9]` Настройки агента
- `[0]` Журнал ошибок и сбоев (Crash History)
- `[R]` Робот KUKA — Синхронизатор сигналов ($IN/$OUT ↔ PLC Tags)
- `[M]` Мастер переезда адресов оборудования и тегов
- `[D]` Диагностика совместимости и готовности системы
- `[S]` Сохранить проект
- `[V]` Сохранить версию (V0 ➔ V1)
- `[P]` Сменить активный проект / процесс TIA Portal
- `[Esc / Q]` Выход

## 📦 Как выложить проект на свой GitHub

Проект полностью подготовлен для отправки на ваш GitHub:
1. Создан файл исключений `.gitignore`.
2. Подключен AI-навык `.agents/skills/tia-portal-engineer/SKILL.md`.

Выполните в консоли в папке проекта:
```bash
# 1. Создать новый пустой репозиторий на https://github.com/new (например, TiaPortalAgent)
# 2. Привязать ваш удаленный репозиторий (замените YOUR_USERNAME и REPO_NAME):
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# 3. Переименовать ветку в main и отправить код:
git branch -M main
git push -u origin main
```
