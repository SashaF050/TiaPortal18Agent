# Siemens TIA Portal Autonomous Agent & Multi-Tool v2.4.0

Интеллектуальный автономный агент, интерактивный TUI-дашборд и MCP JSON-RPC сервер для прямого управления, глубокого аудита, релокации адресов оборудования, синхронизации сигналов промышленных роботов и оптимизации проектов в **Siemens TIA Portal (PublicAPI Openness V14..V20, нативная поддержка V18 Update 5)**.

---

## 🌟 Ключевые возможности v2.4.0

### 1. ⚙️ Расширенная система настроек и автоопределение языка (пункт `[9]`)
- **Умное определение языка ОС**: агент автоматически определяет язык операционной системы (русский, если язык системы русский; иначе — английский) с возможностью ручного переключения (RU / EN).
- **Экспорт тегов с комментариями и без**: глобальная опция `ExportIncludeComments` (Вкл/Выкл) управляет наличием комментариев при экспорте в CSV, в файл сигналов KUKA KRL (`$IN`/`$OUT`) и при пакетной выгрузке.
- **Пользовательский разделитель CSV**: переключение между точкой с запятой (`;` для русской локали Excel) и запятой (`,`).
- **Формат даты резервных копий**: выбор между полным годом (`YYYY.MM.DD`) и кратким (`YY.MM.DD`).
- **Размер страницы вывода**: пагинация длинных списков (10, 20 или 50 строк на экран).
- **Постоянное сохранение настроек**: все параметры сохраняются в JSON-файле `agent_settings.json` и автоматически загружаются при старте.

### 2. 🛡️ Защита от сбоев при закрытии TIA Portal и Headless-режим
- **Remoting-устойчивость**: закрытие окна TIA Portal во время работы агента больше не приводит к падению («самовыпиливанию») процесса. Агент перехватывает разрыв связи, сохраняет состояние дашборда и предлагает переподключиться или открыть проект в автономном режиме.
- **Headless-режим (Без графического интерфейса)**: агент может открывать и полностью анализировать проекты `.ap18` в фоновом режиме без запуска тяжелого GUI TIA Portal (`TiaPortalMode.WithoutUserInterface`). Доступно в меню `[P]` (пункты `[H]` и `[L]`), а также через CLI-параметр `--headless`.

### 3. 🌳 Защита от коллизий версий и движок ветвления проектов (Branch Divergence Engine)
- **Обнаружение дивергенции версий**: если пользователь открыл старую ревизию проекта (например, `V0`), а на диске уже существуют более свежие (`V1`, `V2`), агент распознает развилку версий и предотвращает случайную перезапись:
  - **Trunk (Основная ветка)**: автоматический инкремент от максимальной существующей версии (`V{max+1}`).
  - **Branch (Именованная ветка)**: создание изолированной ветки (например, `_V0_Branch_{Имя}_{Дата}`) для тестирования гипотез или фиксации доработок.
  - **Custom (Свое имя)**: ввод произвольного суффикса.
- **Защита от совпадения имен папок**: автоматическое добавление ревизионных суффиксов (`_rev1`, `_rev2`), если целевая папка уже существует.
- **Манифест версионирования**: генерация файла аудита `version_manifest.txt` в корне созданного проекта с метаданными родительского проекта, автора, времени и среза блоков ПЛК.

### 4. 🤖 Инструменты для AI-агентов (CLI & MCP Server)
- **Чистый машиночитаемый вывод `--json`**: все консольные команды поддерживают флаг `--json` для прямого взаимодействия с LLM/AI-агентами без необходимости парсинга текстовых таблиц.
- **Инспектор тегов (`check-tags`)**: анализ качества базы тегов (неиспользуемые теги, теги без комментариев, наложения логических адресов).
- **Команды CLI**: `blocks`, `devices`, `memory`, `hardware`, `check-tags`, `export-tags`, `audit`, `compile`, `call-tree`, `dependencies`, `export-all`.
- **MCP JSON-RPC методы**: `tia_get_settings`, `tia_update_settings`, `tia_get_system_health`, `tia_export_tags_csv`, `tia_check_tags`.

### 5. 🚚 Мастер переезда адресов оборудования и тегов (пункт `[M]`)
- Интерактивная карта распределения адресного пространства (%I и %Q).
- Сдвиг начальных адресов выбранного устройства (например, с `%I100..131` на `%I200..231`).
- **Контроль конфликтов (Pre-flight Conflict Detection)**: автоматическая проверка наложений на адресное пространство других устройств с блокировкой опасных сдвигов.
- Автоматический сдвиг всех привязанных тегов ПЛК в таблицах тегов.
- **Обязательное резервное копирование**: перед каждым переездом автоматически создается снапшот проекта (`DoSaveProjectVersion`).

### 6. 🤖 Синхронизатор сигналов робота KUKA (пункт `[R]`)
- Двусторонняя синхронизация KRL ↔ TIA Portal PLC Tags:
  - Импорт сигналов `$OUT` (входы ПЛК `%I`) и `$IN` (выходы ПЛК `%Q`).
  - **Обратный экспорт (Reverse Export)** тегов TIA Portal в файл KRL с генерацией корректного синтаксиса `SIGNAL Name $OUT[x]` с учетом настройки экспорта комментариев.
  - Полноценная поддержка комментариев (`;` и `//`), кириллицы и секций FOLD.
  - Редактирование в Блокноте (Notepad) прямо из агента.
  - Добавление одиночного сигнала прямо в консоли без перезагрузки всех тегов.
  - Интерактивный выбор тегов по пробелу (`[Space]`) и создание только отмеченных сигналов.

### 7. 🔍 Диагностика готовности системы и совместимость версий (пункт `[D]`)
- Динамический резолвер сборок `Siemens.Engineering.dll` для любых установленных версий TIA Portal (V14..V20).
- Проверка членства пользователя Windows в группе `Siemens TIA Openness`.
- Проверка и автоматическое внесение агента в Белый список Openness (Whitelist Registry) по нажатию `[W]`.
- Мониторинг запущенных процессов TIA Portal и S7-PLCSIM.

## 🚀 Запуск и Управление

### Главное меню агента
```cmd
build.bat
TiaPortal18Agent.exe
```

Быстрый вызов через PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\tia.ps1 list-processes
powershell -ExecutionPolicy Bypass -File .\tia.ps1 check-tags
powershell -ExecutionPolicy Bypass -File .\tia.ps1 export-tags "Tags.csv" --json
```

Горячие клавиши главного дашборда:
- `[1]` Сводка проекта и аппаратная конфигурация (CPU, модули, IP-адрес)
- `[2]` Структура вызова (Call Structure, навигация и фильтрация Main OB1)
- `[3]` Структура зависимости (Dependency Graph DB → FC/FB → OB1)
- `[4]` Ресурсы памяти (Memory Resources: Load / Work / Retentive)
- `[5]` Диагностика и компилятор TIA Portal
- `[6]` Умный очиститель мусора (Smart Cleaner с защитой Device-IO)
- `[7]` Пакетный экспорт / импорт (SimaticML XML, SCL, CSV)
- `[8]` S7-PLCSIM V18 — Управление симулятором
- `[9]` Настройки агента (Язык, комментарии тегов, CSV, формат дат)
- `[0]` Журнал ошибок и сбоев (Crash History)
- `[R]` Робот KUKA — Синхронизатор сигналов ($IN/$OUT ↔ PLC Tags)
- `[M]` Мастер переезда адресов оборудования и тегов
- `[D]` Диагностика совместимости и готовности системы
- `[S]` Сохранить проект
- `[V]` Сохранить версию (защита от коллизий и ветвление Trunk/Branch)
- `[P]` Сменить активный проект / процесс / Открыть в Headless режиме
- `[Esc / Q]` Выход
